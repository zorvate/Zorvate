# Zorvate

Premium AI-powered software agency platform built with Next.js.

## Features

- Marketing website
- Portfolio CMS
- Pricing CMS
- Client Portal
- Authentication
- Admin Dashboard
- Contact CRM
- Analytics
- Role-based Access Control
- Supabase Backend

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Supabase
- PostgreSQL
- Vercel

## Installation

npm install
npm run dev

## Environment Variables

NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=

...
