# Zorvate Design System

## Brand

Zorvate is a premium digital agency specializing in:

- Modern Websites
- SaaS Applications
- AI Solutions
- UI/UX Design

The website itself must showcase our development quality.

---

## Design Goals

- Premium
- Interactive
- Modern
- Elegant
- Minimal
- Luxurious
- Fast
- Accessible

---

## Inspiration

- Linear
- Stripe
- Framer
- Vercel
- Raycast

---

## Colors

Background:
#09090B

Surface:
#18181B

Primary:
Indigo

Accent:
Cyan

Highlight:
Violet

Success:
Emerald

Danger:
Rose

Avoid large flat blue backgrounds.

---

## Typography

Use modern typography.

Large headlines.

Comfortable spacing.

Readable paragraphs.

---

## Border Radius

Buttons:
12px

Cards:
20px

Dialogs:
24px

---

## Shadows

Use soft shadows.

Prefer glow effects over harsh drop shadows.

---

## Animations

Every interactive element should have a hover state.

Use:

- fade
- slide
- scale
- glow
- stagger
- magnetic buttons
- hover lift

Avoid excessive animations.

---

## Hero

Must create a "wow" moment.

Include:

- Aurora background
- Animated headline
- Floating elements
- Strong CTA
- Client logos

---

## Services

Interactive cards.

Hover animations.

Gradient borders.

Animated icons.

---

## Portfolio

Premium case-study cards.

Hover overlays.

Technology badges.

Live Demo button.

GitHub button.

---

## Forms

Clean.

Minimal.

Accessible.

Beautiful focus states.

---

## Accessibility

Maintain WCAG AA contrast.

Keyboard navigation.

Visible focus.

Semantic HTML.

---

## Performance

Target Lighthouse 95+.

Prefer CSS animations.

Lazy-load heavy assets.

Never reduce performance for visual effects.

---

## Rule

Before changing any UI component ask:

Does this look premium?

Would this impress a client?

If not, improve it.
